# Street & Acre — Website

Source files for **www.streetandacre.com**, hosted on GitHub Pages.

## Folder contents

| Path | What it is |
|------|------------|
| `index.html` | The whole site (single page: Approach, Services, Row & Acre, Markets, About, Contact) |
| `css/styles.css` | All styling — brand colors are defined at the top |
| `js/main.js` | Mobile menu and automatic copyright year |
| `fonts/` | Self-hosted Cormorant Garamond and Jost fonts (SIL Open Font License — license files included) |
| `images/row-and-acre-vineyard.jpg` | Photo used in the Row & Acre section |
| `images/favicon.svg` | S/A browser-tab icon |
| `images/og-image.jpg` | Preview image shown when the link is shared (texts, LinkedIn, etc.) |
| `CNAME` | Tells GitHub Pages this site answers to `www.streetandacre.com` |
| `.nojekyll` | Tells GitHub Pages to serve the files as-is |

## Design

Based on logo **Concept 3 — Clean Contemporary**: widely spaced serif capitals, rust ampersand, S/A monogram with a rust diagonal.

## Before launch — placeholders to fill in (all in `index.html`)

- **DRE license number** — footer: `CA DRE Lic. # [add license number]`
- **Email** — `info@streetandacre.com` appears in the Contact section (twice); set up that inbox or change the address
- **Street address / phone** — commented-out spots in the Contact section
- **About section** — review the bio text (marked with a `REVIEW` comment)

## Updating

Edit files and push to `main` (or use **Add file → Upload files** on GitHub). Pages redeploys automatically within a minute or two.
